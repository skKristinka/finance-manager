# Менеджер личных финансов

Консольное приложение на Python для учёта личных доходов и расходов, контроля баланса и анализа личного бюджета.

## Возможности

- Создание категорий доходов и расходов.
- Хранение информации о финансовых операциях.
- Учёт доходов и расходов на финансовом счёте.
- Просмотр текущего баланса.
- Формирование отчётов по доходам, расходам и категориям.
- Проверка корректности вводимых данных.

Функциональность пользовательского интерфейса и сохранения данных уточняется по мере разработки приложения.

## Технологии

- Python 3.12 или новее.
- Git и GitHub для совместной работы.
- pytest для автоматического тестирования.

## Установка

1. Склонируйте репозиторий:

   ```bash
   git clone git@github.com:skKristinka/finance-manager.git
   ```

2. Перейдите в папку проекта:

   ```bash
   cd finance-manager
   ```

3. Создайте виртуальное окружение:

   ```bash
   python3 -m venv .venv
   ```

4. Активируйте виртуальное окружение:

   ```bash
   source .venv/bin/activate
   ```

5. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

## Запуск приложения

Инструкция по запуску будет добавлена после реализации пользовательского интерфейса.

## Тестирование

Для запуска автоматических тестов выполните команду:

```bash
pytest
```

## Командная работа

Проект разрабатывается несколькими участниками с использованием GitHub.

- Каждый участник работает в отдельной ветке.
- Перед объединением изменений проверяется код и запускаются тесты.
- Изменения объединяются с помощью Pull Request.
- Основная ветка разработки — `develop`.
