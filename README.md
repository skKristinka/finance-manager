Менеджер личных финансов

Консольное приложение на Python для учёта личных доходов и расходов, контроля баланса и анализа личного бюджета.

ВОЗМОЖНОСТИ

- Добавление доходов и расходов.
- Просмотр текущего баланса.
- Формирование отчётов по категориям.
- Проверка корректности вводимых данных.
- Сохранение финансовых операций между запусками.

Функции уточняются по мере разработки приложения.

ТЕХНОЛОГИИ

- Python 3.12 или новее.
- Git и GitHub для совместной работы.
- pytest для автоматического тестирования.

УСТАНОВКА

1. Склонируйте репозиторий:
   git clone git@github.com:skKristinka/finance-manager.git

2. Перейдите в папку проекта:
   cd finance-manager

3. Создайте виртуальное окружение:
   python3 -m venv .venv

4. Активируйте виртуальное окружение:
   source .venv/bin/activate

5. Установите зависимости:
   pip install -r requirements.txt

ЗАПУСК ПРИЛОЖЕНИЯ

Инструкция по запуску будет добавлена после реализации приложения.

ТЕСТИРОВАНИЕ

Для запуска автоматических тестов выполните команду:
pytest

СТРУКТУРА ПРОЕКТА

src/finance_manager/ — исходный код приложения.
tests/ — автоматические тесты.
docs/UML.md — UML-диаграмма классов.
README.md — описание проекта.
documentation.md — техническая документация.
requirements.txt — список зависимостей.
.gitignore — файлы, исключённые из Git.

КОМАНДНАЯ РАБОТА

Проект разрабатывается несколькими участниками с использованием GitHub.

- Каждый участник работает в отдельной ветке.
- Перед объединением изменений необходимо проверять код и запускать тесты.
- Основные изменения согласовываются с командой.

ДОКУМЕНТАЦИЯ

Описание требований и этапов разработки находится в файле documentation.md.
UML-диаграмма классов находится в папке docs и будет уточнена после реализации приложения.
