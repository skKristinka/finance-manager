# Менеджер личных финансов

Консольное приложение на Python для учёта личных доходов и расходов.

## Возможности

- Добавление доходов и расходов.
- Просмотр текущего баланса.
- Отчёт по категориям.
- Проверка корректности введённых данных.
- Сохранение операций между запусками.

## Требования

- Python 3.12 или новее.
- pip.

## Установка

```bash
git clone git@github.com:skKristinka/finance-manager.git
cd finance-manager
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

Инструкция будет дополнена после реализации приложения.

## Тестирование

```bash
pytest
```
