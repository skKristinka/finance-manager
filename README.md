# Менеджер личных финансов

Консольное приложение на Python для учёта доходов и расходов, контроля баланса и анализа бюджета.

## Возможности

- Создание категорий доходов и расходов.
- Добавление доходов и расходов с категорией и описанием.
- Сохранение операций между запусками приложения.
- Просмотр текущего баланса и истории операций.
- Формирование финансовых отчётов по категориям.
- Проверка корректности вводимых данных и возможность отмены операции.
- Интерфейс Lavender Dream с пастельными лавандовыми, голубыми и розовыми акцентами.

## Технологии

- Python 3.12+
- JSON для хранения финансовых операций.
- pytest для автоматического тестирования.

## Установка и запуск

1. Склонируйте репозиторий:

   ```bash
   git clone git@github.com:skKristinka/finance-manager.git
   ```

2. Перейдите в папку проекта:

   ```bash
   cd finance-manager
   ```

3. Создайте виртуальное окружение:

   ```bash
   python3 -m venv .venv
   ```

4. Активируйте его:

   ```bash
   source .venv/bin/activate
   ```

5. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

6. Запустите приложение:

   ```bash
   python run.py
   ```

В Windows виртуальное окружение можно активировать командой `.venv\Scripts\activate`.

## Хранение данных

Операции сохраняются в `data/transactions.json`.

Для изменения расположения файла можно задать переменную окружения `FINANCE_MANAGER_DATA`.

## Тестирование

Для запуска автоматических тестов выполните:

```bash
python -m pytest
```

## Командная работа

Проект разрабатывается несколькими участниками с использованием GitHub.

- Каждый участник работает в отдельной ветке.
- Перед объединением изменений проверяется код и запускаются тесты.
- Изменения объединяются с помощью Pull Request.
- Основная ветка разработки — `develop`.
