# Руководство пользователя — Lavender Dream

## Запуск
Требуется Python 3.12+; дополнительных библиотек интерфейсу не нужно. Из корневой папки проекта выполните:

```bash
python run.py
```

## Меню
- **Добавить доход / расход** — положительная сумма, категория и необязательное описание.
- **Текущий баланс** — баланс с учётом операций.
- **Финансовый отчёт** — доходы, расходы, разница и суммы по категориям.
- **История операций** — даты, суммы, категории и описания.
- **Выход** — завершение приложения.

Сумму можно вводить с точкой или запятой. Неположительная или нечисловая сумма отклоняется; пустая категория не принимается. Для отмены ввода суммы введите `q`.

## Сохранение
История автоматически сохраняется в `data/transactions.json` и загружается при следующем запуске. Чтобы выбрать другой файл, задайте переменную окружения `FINANCE_MANAGER_DATA`.

## Дизайн и архитектура
Lavender Dream использует пастельные лавандовые, голубые и розовые акценты в терминалах с поддержкой ANSI. При `NO_COLOR` или перенаправленном выводе цвета отключаются. Интерфейс использует конструкторы и публичные методы предметной области: `Category`, `Transaction`, `Account.add_transaction()`, `Account.get_balance()` и методы `Report`.
