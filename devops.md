# DevOps и управление проектом

## 1. Общая информация

Проект «Менеджер личных финансов» — консольное приложение на языке Python, предназначенное для учёта доходов и расходов пользователя, контроля баланса и формирования финансовых отчётов.

Для совместной разработки использовались Git и GitHub. Это позволило распределить задачи между участниками команды, отслеживать изменения исходного кода и объединять готовые части проекта.

## 2. Организация репозитория GitHub

Исходный код проекта хранится в репозитории GitHub:

https://github.com/skKristinka/finance-manager

GitHub используется для:
- хранения исходного кода;
- совместной работы участников;
- контроля версий;
- просмотра истории изменений;
- проверки и объединения Pull Request;
- хранения технической документации.

## 3. Организация веток

Для разработки используется несколько веток.

- `develop` — основная ветка разработки, в которую объединяются проверенные изменения.
- `feature/...` — ветки для разработки новых функций.
- `fix/...` — ветки для исправления ошибок.
- `test/...` — ветки для добавления и проверки тестов.
- `docs/...` — ветки для работы с документацией.

Каждый участник выполняет свою задачу в отдельной ветке. Это позволяет не изменять основную версию проекта напрямую и уменьшает вероятность конфликтов.

## 4. Порядок работы с Git

Основные команды, используемые при разработке:

```bash
git clone https://github.com/skKristinka/finance-manager.git
git switch develop
git pull origin develop
git switch -c feature/name
git add .
git commit -m "Описание изменений"
git push -u origin feature/name
```

После отправки изменений на GitHub создаётся Pull Request в ветку `develop`.

## 5. Проверка и объединение изменений

Перед объединением Pull Request необходимо:

1. Проверить изменённые файлы.
2. Убедиться, что изменения соответствуют поставленной задаче.
3. Проверить отсутствие конфликтов.
4. Запустить автоматические тесты.
5. Убедиться, что приложение запускается.
6. После проверки объединить Pull Request с `develop`.

Основная команда для запуска тестов:

```bash
python -m pytest -v
```

## 6. Настройка окружения

Для работы с проектом необходимы:
- Python;
- Git;
- GitHub;
- виртуальное окружение Python;
- библиотека pytest для запуска тестов.

Создание виртуального окружения:

```bash
python3 -m venv .venv
```

Активация на macOS и Linux:

```bash
source .venv/bin/activate
```

Установка зависимостей:

```bash
pip install -r requirements.txt
```

## 7. Запуск приложения

Для запуска программы используется команда:

```bash
python run.py
```

После запуска пользователь может выбрать нужное действие в главном меню приложения.

В рамках проекта были выполнены следующие задачи:

- создан и настроен репозиторий GitHub;
- организована работа с отдельными ветками;
- настроена отправка изменений на GitHub;
- использовались Pull Request для проверки и объединения изменений;
- проведена интеграция пользовательского интерфейса;
