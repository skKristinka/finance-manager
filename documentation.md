Техническая документация проекта «Менеджер личных финансов»

1. Общая информация о проекте

Название проекта:** Менеджер личных финансов.

Тип проекта: Консольное приложение на языке Python.

Цель проекта: Разработка приложения для учёта личных доходов и расходов, контроля текущего баланса и анализа финансов пользователя.

Проект разрабатывается командой с распределением обязанностей между участниками. Каждый участник отвечает за определённую часть разработки, тестирования, безопасности или документации.

2. Назначение и основные функции

Приложение предназначено для ведения личного бюджета. Пользователь сможет записывать доходы и расходы, просматривать финансовую информацию и анализировать распределение денежных средств.

Основные функции приложения:

- добавление доходов;
- добавление расходов;
- просмотр текущего баланса;
- распределение операций по категориям;
- формирование отчётов по категориям;
- проверка корректности вводимых данных;
- сохранение финансовых операций между запусками приложения.

Перечисленные функции являются планируемыми и будут уточняться по мере реализации приложения.

3. Требования к системе

3.1. Функциональные требования

Система должна предоставлять следующие возможности:

1. Добавлять финансовые операции.
2. Различать доходы и расходы.
3. Указывать сумму и категорию операции.
4. Рассчитывать текущий баланс на основе финансовых операций.
5. Формировать отчёты по категориям.
6. Проверять корректность вводимых данных.
7. Сохранять данные для последующего использования.

3.2. Нефункциональные требования

- Простота использования: команды приложения должны быть понятными пользователю.
- Надёжность: некорректный ввод не должен приводить к неожиданному завершению программы.
- Сопровождаемость: код должен быть разделён на логические модули.
- Тестируемость: основные функции должны проверяться автоматическими тестами.
- Безопасность: приложение не должно хранить пароли и другие секретные данные в исходном коде.

 4. Технологии проекта

Для разработки проекта планируется использовать:

- Python — основной язык программирования.
- Git — система контроля версий.
- GitHub — совместная работа над исходным кодом.
- pytest — инструмент автоматического тестирования.

Версия Python и дополнительные зависимости уточняются в файлах проекта.

5. Участники и распределение обязанностей

Работа над проектом разделена между участниками:

1. Разработка основной логики: создание классов и реализация бизнес-логики приложения.
2. Разработка интерфейса: организация взаимодействия пользователя с приложением.
3. Безопасность и валидация: проверка входных данных и обработка ошибок.
4. Тестирование: разработка и запуск автоматических тестов.
5. Техническая документация и DevOps: организация репозитория GitHub, подготовка README, UML-диаграммы, технической документации и презентации.

6. Статус документации

На начальном этапе подготовлена структура репозитория, созданы основные файлы и определены планируемые функции приложения.

Архитектура, структура классов, формат хранения данных и команды запуска будут уточнены после реализации и согласования основных компонентов проекта.
